# Synaptic A220 MSFS 2020 livery template

This directory contains only the generic structural files required by a known-good Synaptic A220 MSFS 2020 livery package:

- `model.ATC/exterior.bin`
- `model.ATC/exterior.gltf`
- `model.ATC/Exterior.xml`
- `model.ATC/model.CFG`
- `TEXTURE.CFG`

Source archive SHA-256: `0116f32f08266c67ef6ab3b605109f2a51b0c6a3a8c220a171f77365de4aef8e`

The source was supplied privately for conversion validation. Airline-specific textures, thumbnails, configuration, branding, and the bundled executable were not retained. The builder combines these generic structural files only with airDash-owned texture data.
